# TezWork — сағаттық жұмыс платформасы және AI ауысым көмекшісі

Қазақстандағы бір ауысымдық, бір күндік жұмыс үшін мобильді қосымша: жұмыс беруші ауысым жариялайды, жұмыс іздеуші бір түртумен жазылады, төлем мен рейтинг платформа ішінде өтеді.
AI-SANA HACKATHON 2026 · «210» командасы (METU студенттері).

- **Демо (веб):** `npx expo start --web` → http://localhost:8081 (төмендегі «Іске қосу» бөлімін қараңыз)
- **Демо аккаунттар:** жұмысшы `+7 777 123 45 67`, жұмыс беруші `+7 777 987 65 43` — код экранда автоматты шығады (демо режим)

## 1. Мақсаты мен міндеттері

**Мәселе.** Дүкен, қойма, кафе, іс-шара бір күнге адам іздегенде WhatsApp/Telegram топтарына хабарландыру жазады: жұмысшы кім екені белгісіз, келді-келмегені тексерілмейді, төлем қолма-қол, нөмір бәріне ашық. Жұмыс іздеушіге (студенттер, қосымша табыс іздейтіндер) сенімді, тез ақша табатын орын жоқ.

**Мақсат.** Бір ауысымға жұмыс табуды және адам табуды минуттарға қысқарту, екі жаққа да қауіпсіз ету.

**Міндеттер:**
1. Жұмыс беруші ауысымды тез жариялай алсын — **AI көмекші** еркін мәтіннен форманы өзі толтырады.
2. Жұмысшы ауысымды қала, күн, санат бойынша тауып, бір түртумен өтінім берсін; жұмыс беруші өтінім бергендердің ішінен керегін «Қабылдау» арқылы таңдайды, орын толғанда ауысым лентадан жасырылады.
3. Тараптар тексерілген болсын: ЖСН/БСН бақылау цифры, жас шегі (жұмысшы 16+, жұмыс беруші 18+).
4. Қабылданған жұмысшы жұмыс біткенде «Жұмыс аяқталды» басады; жұмыс беруші «Растау және төлеу» басқанда ақы оның әмиянынан жұмысшының әмиянына автоматты түседі; барлық орын төленгенде вакансия өзі жабылады. Екі жақты рейтинг.
5. Жұмыс беруші өтінім берушінің нөмірін бірден көреді; жұмысшыға жұмыс берушінің нөмірі тек қабылданғаннан кейін ашылады.

## 2. AI шешімі: ауысым көмекшісі

Жұмыс беруші ауысымды өз сөзімен, қазақша не орысша жазады:

> Ертең Алматыда Абай даңғылы 10-ға 2 жүк тиеуші керек, 9-дан 18-ге дейін, 15 мың теңге. Жұмыс киімі беріледі.

AI жариялау формасының өрістерін толтырады: атауы, санаты, қаласы, мекенжайы, күні («ертең», «сенбі» → нақты күн), басталу/аяқталу уақыты (түнгі ауысымды қоса), төлем түрі (ауысымға/сағатына) мен сомасы («15 мың», «15к»), адам саны, сипаттамасы. Мәтінде жоқ өрістерді атап көрсетеді. Жұмыс беруші тексеріп, «Жариялау» басады — AI өзі ештеңе жарияламайды.

**Қалай жұмыс істейді:**

```
Қосымша (create.tsx → AiAssist)
   │  supabase.functions.invoke('ai-shift-draft', { text })     — JWT міндетті
   ▼
Supabase Edge Function  supabase/functions/ai-shift-draft
   │  рөлді тексереді (тек жұмыс беруші) · мәтін ≤ 800 таңба
   │  Gemini API (тегін тариф): gemini-3.6-flash → бос болмаса 3.8-flash → 3.5/3.1-flash-lite
   │  немесе Claude API: claude-opus-5-5
   │  structured outputs — жауап әрдайым JSON Schema бойынша
   │  жауапты тексеріп шектейді (уақыт 30 мин қадамы, күн 14 күн ішінде, санат тізімнен)
   ▼
Форма өрістері толады → адам тексереді → жариялайды
```

- **Модель:** Gemini 3.6 Flash (Google), [Gemini API](https://ai.google.dev/gemini-api/docs) тегін тарифі арқылы; модель бос болмаса (503) не 15 секундта жауап бермесе, Gemini 3.8 Flash, сосын Flash-Lite модельдері қолданылады. Балама — Claude Opus 5.5 (Anthropic): `AI_PROVIDER=claude` қойылса, сол қолданылады (нұсқаулық пен схема бірдей). Оқыту жүргізілмеген (zero-shot): нұсқаулық + JSON Schema шектеуі.
- **Неге LLM:** хабарландырулар қысқа, бейресми, екі тілде, қате жазылған; «кешкі 8», «бүрсігүні», «15к» сияқты өрнектерді ереже жазып қамту қиын. Structured outputs жауаптың әрдайым форма күткен құрылымда келуіне кепілдік береді.
- **Қауіпсіздік:** API кілті тек Supabase Secrets-те (`GEMINI_API_KEY` / `ANTHROPIC_API_KEY`), қосымшада жоқ. Хабарландыру мәтіні модельге «дерек» ретінде беріледі, нұсқау ретінде емес. Дербес деректер (ЖСН, телефон) модельге жіберілмейді.

## 5. Шектеулер

- **AI қателесуі мүмкін** — сондықтан тек форманы толтырады, жарияламайды; адам тексереді. Күн тек алдағы 14 күн ішінде, уақыт 30 минут қадамымен.
- **AI интернет пен API кілтін қажет етеді.** Gemini тегін тарифінің квотасы шағын: тест кезінде бір модельдің квотасы шамамен 20 сұраныстан кейін бітті, жүйе келесі тегін модельге (Flash-Lite) өзі ауысты. Барлығы бітсе, AI «бос емес» деп, форма қолмен толтырылады. Квота тәулігіне бір рет жаңарады; `GEMINI_API_KEY`-ге басқа Google жобасының кілтін үтір арқылы қосса, квота көбейеді. Тегін тарифте Google сұраныстарды өз өнімдерін жақсартуға пайдалануы мүмкін — сондықтан модельге тек хабарландыру мәтіні барады, дербес дерек жіберілмейді.
- **Төлем — тест режимі:** әмиян нақты ақша аудармайды; нақты провайдер (Kaspi / Halyk ePay / CloudPayments) — келесі кезең.
- **SMS — демо режим:** код тек Supabase тест нөмірлеріне; нақты SMS провайдерін қосу: [docs/SMS-SETUP.md](docs/SMS-SETUP.md).
- **ЖСН** бақылау цифры бойынша тексеріледі, eGov арқылы иесі расталмайды.
- **Сервер аймағы** — ap-southeast-2 (Сидней): Қазақстаннан әр сұраныс 0,2–0,4 с; қосымша кэш пен параллель сұраныстармен өтейді.

## 7. Іске қосу

```bash
npm install
npx expo start          # телефонда Expo Go, немесе w — веб
npx expo start --web    # тек веб
```

`.env` файлында:

```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
```

**Supabase:**
1. `supabase/migrations/` ішіндегі SQL-дерді ретімен орындаңыз (SQL Editor немесе `supabase db push`).
2. Edge Functions: `supabase functions deploy ai-shift-draft` (және SMS үшін `send-sms-hook`).
3. Secrets: `GEMINI_API_KEY` — aistudio.google.com кілті (тегін). Не `ANTHROPIC_API_KEY` — console.anthropic.com кілті. Екеуі де болса, Gemini қолданылады; `AI_PROVIDER=claude` ауыстырады. Модельді `GEMINI_MODEL` / `AI_MODEL` арқылы өзгертуге болады.
4. Authentication → Phone → Test Phone Numbers: `77771234567=123456`, `77779876543=123456` (демо аккаунттар).

**Тексеру:**

```bash
npx tsc --noEmit
npx expo lint
node scripts/ai-eval/run.mjs
node scripts/e2e/approval.mjs   # өтінім → қабылдау → «Жұмыс аяқталды»: екі демо аккаунтпен (E2E_PAY=1: төлеммен)
```
