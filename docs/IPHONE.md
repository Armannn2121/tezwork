# TezWork-ті iPhone-ға тегін орнату (Expo Go)

Ақылы Apple Developer аккаунтынсыз iPhone-да қосымшаны ашудың жалғыз жолы — **Expo Go**.
Қосымша Expo Go ішінде ашылады (жеке иконка болмайды), бірақ барлық экран мен мүмкіндік жұмыс істейді.

## 1. iPhone-да

1. App Store-дан **Expo Go** қосымшасын орнатыңыз.
2. Ашып, Expo аккаунтымен кіріңіз (тегін, expo.dev-те тіркеледі) — міндетті емес, бірақ ыңғайлы.

## 2. Компьютерде

Жоба қалтасында терминалды ашып:

```bash
npm run phone
```

Бұл `expo start --tunnel` іске қосады. Алғаш рет `@expo/ngrok` орнатуды сұраса — `Y` басыңыз.
Терминалда QR-код шығады.

## 3. Ашу

iPhone-дағы **Камерамен** QR-кодты сканерлеңіз → «Expo Go-да ашу» батырмасын басыңыз.

`--tunnel` режимінің арқасында телефон компьютермен бір Wi-Fi-да болмаса да болады —
мобильді интернетпен де, басқа желіден де ашылады.

## Жаңартулар

Компьютерде кодты өзгертсеңіз (немесе мен өзгертсем), өзгеріс телефонда **бірден** көрінеді —
қайта орнатудың қажеті жоқ. Тек компьютер қосулы тұрып, `npm run phone` жұмыс істеп тұруы керек.

## Шектеулер

| Мүмкіндік | Expo Go-да |
|---|---|
| Барлық экрандар, кіру, ауысымдар, рейтинг, байланыс | ✅ жұмыс істейді |
| Ауысымнан 1 сағат бұрын еске салу (телефонның өзінде) | ✅ жұмыс істейді |
| Серверден келетін push (мыс. «жаңа жұмысшы жазылды») | ❌ ақылы Apple аккаунты + жеке build керек |
| Компьютерсіз ашу | ❌ компьютер мен `npm run phone` қосулы болуы керек |
| Жеке иконка / App Store | ❌ ақылы Apple аккаунты керек |

## Егер «Project is incompatible with this version of Expo Go» деп шықса

Жоба Expo SDK 58-де. App Store-дағы Expo Go жаңа SDK-ны кейде бірнеше апта кешігіп қолдайды.
Бұл жағдайда: App Store-да Expo Go-ны жаңартып көріңіз; болмаса маған айтыңыз — басқа жолын қарастырамыз.

## Келешекте (толық қосымша)

Apple Developer ($99/жыл) алғанда: EAS Build арқылы жеке TezWork қосымшасы (TestFlight),
серверден push-хабарламалар және компьютерсіз автоматты жаңартулар (EAS Update) қосылады.
